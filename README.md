# ⚫⚪ Othello (Reversi)

เกม Othello บนเว็บ เขียนด้วย HTML, CSS และ JavaScript ล้วน ในไฟล์เดียว (`index.html`)

## ฟีเจอร์

- **เล่นกับ AI** 3 ระดับ: ง่าย, ปานกลาง, ยาก (Minimax + Alpha-Beta Pruning)
- **ผู้เล่น 2 คน** บนเครื่องเดียวกัน
- เลือกเล่นเป็นหมากดำ (เล่นก่อน) หรือหมากขาว
- ปุ่มแนะนำตำแหน่งที่ควรลง
- แสดงจุดตำแหน่งที่ลงได้ และตำแหน่งที่ลงล่าสุด

## กติกา

วางหมากให้หมากฝ่ายตรงข้ามอยู่ระหว่างหมากใหม่กับหมากของคุณ (แนวตั้ง แนวนอน หรือแนวทแยง)
หมากที่ถูกหนีบจะถูกพลิกเป็นสีของคุณ ถ้าไม่มีตำแหน่งลงต้องข้ามตา
เกมจบเมื่อทั้งสองฝ่ายลงไม่ได้ ฝ่ายที่มีหมากมากกว่าชนะ

## เริ่มใช้งาน

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
